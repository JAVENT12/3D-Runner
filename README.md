# 3D-Runner

A third-person runner developed in Unity, inspired by *Temple Run*, with an emphasis on simple mechanics, responsive controls, and obstacle-based gameplay.

## Game Overview

The player navigates a three-lane course while avoiding stationary and moving obstacles. The objective is to survive as long as possible while accumulating points based on distance traveled.

Our current scope prioritizes a functional gameplay loop over complex environments or advanced mechanics.

## Planned Gameplay Features

- **Movement:** Automatic forward movement with three-lane switching.
- **Jumping:** Avoid low obstacles using a basic jump mechanic.
- **Obstacles:** Stationary and moving hazards with collision detection.
- **Scoring:** Distance-based score tracking.
- **Camera:** Third-person camera that follows the player.
- **Game States:** Main menu, active gameplay, and game-over screen with restart functionality.

## Technical Requirements

- Two lighting types (Directional and Point)
- Camera movement
- Character or obstacle animation
- Moving obstacles
- Functional menus

## Planned Controls

| Input | Action |
|---|---|
| A / Left Arrow | Move left |
| D / Right Arrow | Move right |
| Space | Jump |

## Development Tools

- **Game Engine:** Unity
- **Programming Language:** C#
- **Version Control:** Git / GitHub
- **Target Platform:** PC

## Development Approach

The project builds on an existing Unity prototype. Development will focus on integrating the team's contributions, implementing the required gameplay systems, and maintaining a stable, playable build.

Additional features will be considered only after the core mechanics and project requirements are functional.
